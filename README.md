# Китай Логистика 765

Демонстрационный редизайн сайта logistic-company.pro. Оригинальный логотип сохранен. Перенесены 5 тарифов, услуги, условия оплаты, процесс доставки, команда, показатели компании, адреса складов, контакты и ссылка на отзывы.

Статический сайт без установки зависимостей: `index.html`, `styles.css`, `app.js`, `assets/`. Все изображения локальные.

Расчет формирует текст запроса. Посетитель копирует его для Telegram или отправляет через свой почтовый клиент. Серверная отправка заявок не подключена; форма не показывает ложное сообщение об отправке.

GitHub Actions публикует сайт через GitHub Pages. Для закрытого репозитория доступность Pages зависит от тарифа GitHub и настроек аккаунта. Демонстрация закрыта от поисковой индексации через robots meta.

Источник данных: https://logistic-company.pro/, перенос 13 октября 2026 года. Показатели 8 лет, 80% и 100% сохранены как заявления исходного сайта, без независимой проверки.
