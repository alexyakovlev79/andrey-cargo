# Китай Логистика 765

Демонстрационный сайт на основе версии Claude, предоставленной Андреем 13 октября 2026 года. Сохранены структура, тёмная тема, тексты, тарифы и значок «765» этой версии. Основные CTA ярко-бирюзовые с тёмным текстом, дополнительный акцент — золотой.

Статический сайт без установки зависимостей: `index.html`, `styles.css`, `app.js`, `assets/logo.png`. GitHub Actions публикует его на GitHub Pages. Демонстрация закрыта от индексации через robots meta.

Форма показывает подготовленный текст запроса и ссылки для отправки посетителем в Telegram или через почтовый клиент. Заявки автоматически не отправляются. Текст можно отредактировать и скопировать. Исправлены формат номера WhatsApp, ссылка на отзывы, расположение мобильного меню, адаптивность и доступность полей формы.

Проверки в `scripts/check-ui.cjs` выполняются на настольной, планшетной и мобильных ширинах, включая узкий экран 320 px. Проверяются значок «765», переполнение, CTA, меню и подготовка запроса.

Данные и отзывы сохранены из предоставленного Андреем файла. Показатели компании не являются результатом независимой проверки.
